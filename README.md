A simple build to settle arguments over "What's for Dinner?"
This build assumes you're using a half-circle with 6 evenly spaced "slices", each containing a dinner option, but the code can be easily modified.
The enclosed .pdf has several choices.

Parts:
- Raspberry Pi Pico (any variety)
- Tower SG92R micro servo (or equivalent) https://www.adafruit.com/product/4326
- Breadboard button (any standard should do): ex: Tactile Button switch (6mm) x 20 pack
- pin-pin jumper wires
- breadboard
- micro USB cable

Assumes:
- button wired to pin GP6
- servo wired to pin GP13 w/power to 5v

Calibrate the min/max as needed for your own servo.
